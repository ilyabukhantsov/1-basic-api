# Test Assignment for a Go Developer — API Development

## Task Description

The goal is to develop a simple API for a product catalog. The application should contain:

* Product categories
* Individual products that belong to one or more categories (a product can belong to multiple categories)
* Users who can authenticate

The API should support the following actions:

* Retrieve a list of all categories
* Retrieve a list of products in a specific category
* User authentication
* Create/Edit/Delete a category (for authenticated users)
* Create/Edit/Delete a product (for authenticated users)

## Technical Requirements

1. The application must be written in Golang
2. The application must not use any framework, although various packages may be installed
3. API responses must be provided in JSON format
4. The completed assignment must be published on GitHub and include instructions on how to run the project. You must also provide an estimate of how much time was spent on each part of the project

## Evaluation Criteria

* API architecture and organization
* Proper handling of exceptional situations and errors
* Code test coverage
